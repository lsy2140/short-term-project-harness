## 시안 틀 (`$web-ui 시안` · 후보 md 1개당 1장)
- 목적: 사람이 색·밀도·배치를 고르는 미리보기다. 글자가 조금 깨져도 다시 만들지 않는다.
- 도구: Codex 내장 이미지 생성(`codex features list` 에 `image_generation … true`). 사전 체험에서 1장이 파일로 저장된 경우만 쓰고, 아니면 아래 HTML 시안.
- 채울 값: 후보 md 의 색·서체·간격(refs/INDEX.md 행 + 원문 Colors·Typography 절)과 PRD 4절 화면. 시안끼리 화면 구성은 같게, 스타일만 다르게.
- 이 틀은 위의 '공통 꼬리'를 붙이지 않는다(일러스트가 아니라 화면 시안).

```
<과제 화면 이름> 웹 화면 시안 1장. 데스크톱 1280×800 가로형(모바일 유형은 390×844 세로형, 크기를 못 고르면 그 방향의 기본값), 브라우저 테두리 없이 화면만 정면으로.
화면 구성(REFERENCE.md 유형 <번호> 와이어, 위에서 아래로): <상단바 / 툴바 / 상태 배너 / stat 3칸 / 설비 보드 + 알림 / 표>.
스타일(출처 refs/<…>.md): 바탕 <hex>, 패널 <hex>, 글자 <hex>, 강조 1색 <hex>(주 버튼·선택에만), 모서리 <px>, 간격 <촘촘|보통|여유>, 서체 느낌 <…>, 분위기 <3단어>.
글자는 한국어 짧은 명사와 숫자만(과제 데이터의 열 이름). 로고·서비스 이름·워터마크·사람 사진 없음. 평면 화면, 그림자 거의 없음, 장식 그라디언트·광원 없음.
```

- 저장: `static/draft/sian_N.png`(도구가 다른 곳에 저장하면 복사). 기록 1줄(모델·시각·후보 md)은 B_web.md ⑤.
- 이미지 생성 도구가 없거나 실패하면 HTML 시안(같은 템플릿, 토큰만 다름):

```bash
mkdir -p static/draft && cp design-kit/{tokens.css,base.css,components.css,kit.js,icons.svg,data.json} static/draft/
# 후보마다 static/draft/sian_N.css 1줄: :root { --brand: #…; --brand-rgb: R, G, B; --brand-deep: #…; --brand-soft: #…; --paper: #…; --panel: #…; --ink: #…; --r-sm: …px; --r-md: …px; }
for N in 1 2 3; do sed -e "s#\.\./components\.css\">#components.css\"><link rel=\"stylesheet\" href=\"sian_$N.css\">#" -e 's#\.\./##g' design-kit/templates/<템플릿>.html > static/draft/sian_$N.html; done
```
- 캡처: 앱 포트 8000 으로 `static/` 을 연다(앱 서버가 이미 있으면 그대로, 없으면 `python3 design-kit/serve.py 8000 --dir static --index draft/sian_1.html` → 포트 보고). DESIGN.md 캡처 절 명령에서 창 `1280,800`(모바일 `390,844`)·저장 `static/draft/sian_N.png`·주소 `/draft/sian_N.html` 만 바꾼다. 사람이 고를 때까지 켜 두고(미리보기 `/draft/sian_N.png`·`.html`), 고른 뒤 끄고 앱 서버로 바꾼다. 크롬이 없으면 미리보기 경로만 보고한다.
- 보고 1줄씩: `시안 N · refs/<…>.md · 분위기 3단어 · <미리보기 경로>` → 사람이 `시안 N 선택` 할 때까지 본 화면은 만들지 않는다.
- 고른 뒤 이 폴더는 지우지 않는다(디자인 결정의 근거). 시안 css 의 hex 는 ui_check 에서 WARN(연결 CSS)일 뿐이고, 본 화면은 tokens.css 만 쓴다.
