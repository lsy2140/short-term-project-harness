## 과제 전용 틀 (조건: 사전 체험에서 생성 1장이 파일로 저장됨 · 5장 이하)
- 시점: CP2 freeze 뒤 `$web-ui 최종` 에서 화면 교체. 연결 신호를 기다리는 빈 시간에 미리 생성해 `static/img/21-*.png` 에 두기만 하는 것은 된다(화면 교체는 freeze 뒤).
- 순서·주제는 DESIGN_과제.md 9절 그림 계획 표(시안의 그림 자리)를 따른다. 기록(모델·날짜·프롬프트 번호)은 아래 생성 기록 표에 1줄.
- 파일 크기: 생성 PNG 긴 변 1024px 이하 · 장당 500KB 이하 · `static/img/` 합계 3MB 이하(넘으면 Python 으로 축소하거나 장수를 줄인다).
```

## 시안 틀 (`$web-ui 시안` · 5개 · 시안 1개 = 후보 md 1개 + 배치 1개 + 그림 자리 1~2)
- 목적: 사람이 **색(md)·배치·그림 자리** 3가지를 고르는 미리보기다. 글자가 조금 깨져도 다시 만들지 않는다.
- 도구: Codex 내장 이미지 생성(`codex features list` 에 `image_generation … true`). 사전 체험에서 1장이 파일로 저장된 경우만 쓰고, 아니면 아래 HTML 시안. 한 번에 1장씩 5회 호출, 실패한 번호만 다시.
- 수: 5개 `static/draft/sian_1..5.png`. 시안 N 은 배치 N 을 기본으로(5개가 서로 다른 배치). 시안 1개당 1장만(데스크톱 유형 1280×800, 모바일 유형 390×844; 다른 폭의 시안은 만들지 않는다).
- 채울 값: 후보 md 의 색·서체·간격(refs/INDEX.md 행 + 원문 Colors·Typography 절) + PRD 4·5 필수 블록 + 배치 N + 그림 자리 1~2(주제는 과제 도메인). 시안끼리 필수 블록은 같고, 배치·그림 자리·강조 방식은 다르게.
- 이 틀은 위의 '공통 꼬리'를 붙이지 않는다(일러스트가 아니라 화면 시안). 그림 자리는 빈 박스가 아니라 일러스트가 실제로 그려진 상태로 나오게 쓴다.

배치 5종 (시안 N = 배치 N · 데스크톱 유형 1·2·3·5 와 모바일 유형 4 는 예가 다르다):

| 번호 | 이름 | 한 줄 설명 | 그림 자리 위치 | 데스크톱 유형(1·2·3·5) 예 | 모바일 유형(4) 예 |
|---|---|---|---|---|---|
| ① | 좌 목록 / 우 상세(split) (모바일: 큰 숫자+목록) | 목록 35~40% 와 상세를 나란히, 선택 행 틴트 | 상세 개요 16/9 1개 + 빈 목록 1/1 | 유형 2: 로트 목록 | 상세 탭·kv 표 | 큰 숫자 1 → CTA → 56px 행 · 그림: 빈 목록 1/1 |
| ② | 상단 요약 띠 + 전폭 표 (모바일: 카드) | 위에 stat·배너 띠, 아래 전폭 표 | 요약 띠 오른쪽 끝 4/3 1개 또는 빈 결과 1/1 | 유형 1: stat → 알림 띠 → 로트 표 | 항목마다 카드 1장, 세로 1열 · 그림: 카드 머리 1/1 |
| ③ | 카드 그리드 (모바일: 탭 분할) | 항목을 카드 2~3열로, 카드마다 작은 그림 자리 | 카드 안 작은 1/1(틴트 면) + 머리 띠 21/9 선택 | 유형 1·5: 설비·기능을 카드로 | 상단 탭 3개 → 섹션 전환 · 그림: 첫 섹션 머리 4/3 |
| ④ | 좌 필터·내비 패널 + 본문 (모바일: 그림 상단) | 왼쪽 180~240px 패널에 필터·내비, 오른쪽 본문 | 본문 머리 4/3 1개 또는 빈 결과 1/1 | 유형 3: 좌 내비 + 폼 / 유형 2: 좌 필터 + 표 | 그림 4/3 → 큰 숫자 → 목록 · 그림: 상단 4/3 |
| ⑤ | 상단 일러스트 띠(3/1) 또는 소형 히어로(좌 글 + 우 그림 4/3) + 내용 (모바일: 체크리스트) | 맨 위 그림 띠 뒤에 내용 | 상단 3/1 1개 또는 우측 4/3 1개 | 유형 5: 히어로 + 기능 3열 / 유형 1: 띠 + stat | 할 일 행 + 체크 · 그림: 완료 1/1 |

```
<과제 화면 이름> 웹 화면 시안 1장. 데스크톱 1280×800 가로형(모바일 유형은 390×844 세로형, 크기를 못 고르면 그 방향의 기본값), 브라우저 테두리 없이 화면만 정면으로.
필수 블록(PRD 4·5, 5개 시안 모두 같음): <상단바 / 툴바 / 상태 배너 / stat / 설비 보드 / 알림 / 표>.
배치: <5종 중 1개 설명 1~2줄. 예) 좌 목록 40% + 우 상세 60%, 상세는 탭 3개와 kv 표, 선택 행 틴트>.
그림: <위치·비율·주제 1~2개. 예) 상세 개요 탭 16/9 — 검사 장비를 지나는 웨이퍼 캐리어 / 빈 알림 1/1 — 조용한 종>. 2색 플랫 일러스트가 그 자리에 실제로 그려진 상태(빈 박스·'이미지' 글자 아님), 브랜드색 1색 + 연한 면 1색, 그림 안 글자·로고 없음.
스타일(출처 refs/<…>.md): 바탕 <hex>, 패널 <hex>, 글자 <hex>, 강조 1색 <hex>(주 버튼·선택에만), 모서리 <px>, 간격 <촘촘|보통|여유>, 서체 느낌 <…>, 분위기 <3단어>.
글자는 한국어 짧은 명사와 숫자만(과제 데이터의 열 이름). 로고·서비스 이름·워터마크·사람 사진 없음. 평면 화면, 그림자 거의 없음, 장식 그라디언트·광원 없음.

- 저장: `static/draft/sian_N.png`(도구가 다른 곳에 저장하면 복사). 기록 1줄(모델·시각·후보 md·배치)은 B_web.md ⑤.
- 이미지 생성 도구가 없거나 실패하면 HTML 시안(같은 템플릿, 토큰 + 배치 CSS 1줄만 다름):

```bash
mkdir -p static/draft && cp design-kit/{tokens.css,base.css,components.css,kit.js,icons.svg,data.json} static/draft/
# 후보마다 static/draft/sian_N.css 1줄: :root { --brand: #…; --brand-rgb: R, G, B; --brand-deep: #…; --brand-soft: #…; --paper: #…; --panel: #…; --ink: #…; --r-sm: …px; --r-md: …px; }
# 배치 차이는 같은 파일에 CSS 1줄 더(키트 규칙보다 특이도가 같거나 높아야 먹는다): 예) .split{grid-template-columns:1fr}  또는  .panels>[class*="span-"]{grid-column:span 12}(전부 전폭 1열)  또는  .panels>.span-8{grid-column:span 6}
for N in 1 2 3 4 5; do sed -e "s#\.\./components\.css\">#components.css\"><link rel=\"stylesheet\" href=\"sian_$N.css\">#" -e 's#\.\./##g' design-kit/templates/<템플릿>.html > static/draft/sian_$N.html; done
```
- CSS 1줄로 배치를 흉내 내지 못하는 시안은 "색만 다름" 을 보고 줄에 적는다.
- 캡처: 앱 포트 8000 으로 `static/` 을 연다(앱 서버가 이미 있으면 그대로, 없으면 `python3 design-kit/serve.py 8000 --dir static --index draft/sian_1.html` → 포트 보고). CHROME 변수는 DESIGN.md 캡처 절과 같고, 루프만 시안용으로(모바일 유형은 창 `390,844`):
  `for N in 1 2 3 4 5; do "$CHROME" --headless=new --disable-gpu --no-sandbox --user-data-dir=.tmp/chrome --window-size=1280,800 --screenshot=static/draft/sian_$N.png "http://127.0.0.1:8000/draft/sian_$N.html"; done`
  사람이 고를 때까지 켜 두고(미리보기 `/draft/sian_N.png`·`.html`), 고른 뒤 끄고 앱 서버로 바꾼다. 크롬이 없으면 미리보기 경로만 보고한다.
- 보고 1줄씩: `시안 N · refs/<…>.md · 배치 <이름> · 분위기 3단어 · 그림 자리 <위치> · <미리보기 경로>`(모바일 유형은 배치 표의 괄호 이름) → 사람이 `시안 N 선택` 할 때까지 본 화면은 만들지 않는다. 사람은 바꿀 점에 `색은 시안 M 것`·`배치는 시안 M 것`·`그림 자리는 시안 M 것` 을 쓸 수 있다.
- 고른 뒤 정리: 고른 시안 1장만 `static/draft/` 에 남기고 나머지 4장은 `.tmp/draft/` 로 옮긴다(제출물 크기). HTML 폴백이면 복사한 css·js·json·`sian_N.html` 도 같이 옮긴다. 비교 근거는 DESIGN_과제.md 0절 '다른 후보' 표(시안·md·배치·안 고른 이유), 고른 배치는 1-1 배치 표, 그림 자리는 9절 그림 계획 표. 시안 css 의 hex 는 ui_check 에서 WARN(연결 CSS)일 뿐이고, 본 화면은 tokens.css 만 쓴다.
