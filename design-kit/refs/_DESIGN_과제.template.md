# DESIGN_과제.md — <과제 이름> 화면 디자인 (고른 시안 기준)
상태: 초안 · 갱신 __:__ · 쓰는 곳: B_web(단일 세션은 A)

- 이 파일 = 사람이 고른 시안 1개 + 과제 요구(PRD 4절)를 합친 이 과제 전용 디자인 규칙. 틀 위치: `design-kit/refs/_DESIGN_과제.template.md`.
- 사람 선택 = 색(md)·배치·그림 자리 3가지. 색은 2절, 배치는 1-1절, 그림 자리는 9절에 적는다(바꿀 점에 `색은 시안 M 것`·`배치는 시안 M 것`·`그림 자리는 시안 M 것` 이 있으면 그대로 반영).
- 칸은 짧게(한 칸 = 한 사실). 모르면 '-'. 원문 md 를 통째로 옮기지 않는다.
- hex(색 값)는 2절에 옮겨 적기만 하고, 실제로 쓰는 곳은 키트에서 복사한 `static/tokens.css` 한 곳이다(design-kit 원본은 그대로).

## 2. 색 (5~7개 · 값은 static/tokens.css 에만 쓴다)
| tokens.css 변수 | 값(hex) | 원문 이름 | 쓰는 곳 |
|---|---|---|---|
| `--brand` | # | primary | 주 버튼 · 선택 표시 · 링크 |
| `--brand-rgb` | R, G, B | (--brand 와 같은 색) | 포커스 링(키보드 선택 테두리) |
| `--brand-deep` | # | primary-pressed | 브랜드색 글자 · 눌린 상태 |
| `--brand-soft` | # | primary-weak | 선택된 행 · 칩 바탕 |
| `--paper` | # | canvas | 페이지 바탕 |
| `--panel` | # | surface | 카드 · 표 바탕 |
| `--ink` | # | ink / text | 본문 글자 |
- 상태색 5쌍(`--ok` `--warn` `--bad` `--info` `--off`)은 바꾸지 않는다(정상·주의·고장 뜻이 화면마다 같아야 함).
- 확인: `python3 design-kit/ui_check.py <URL>` 의 `contrast (tokens)` PASS = 글자와 바탕의 밝기 차이 4.5:1 이상.
- 어두운 바탕 원문이면: 이 표는 밝은 바탕으로 옮기고 어두운 색은 상단바·강조 띠 1곳에만(대비 확인).

## 6. 문구 톤 (5줄)
- 말투: 예) 해요체 / 합니다체 중 1개
