사용 절차

자세한 것은 DESIGN.md. 여기서는 순서만.

  1. templates/ 에서 가장 가까운 템플릿을 과제 폴더로 복사하고 CSS 3파일도 복사한다.
  2. 페이지는 var(--토큰) 만 쓴다. 새 hex·새 반경·외부 URL 금지.
  3. data.json 자리에 과제 데이터(API 또는 파일)를 넣고 render() 의 data→DOM 매핑 표를 DECISIONS.md 에 적는다.
  4. python3 design-kit/ui_check.py http://localhost:PORT/ PASS → 미리보기에서 데스크톱·390px HUMAN_CHECK 4질문 → 커밋.
