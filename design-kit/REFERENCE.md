## 1. 제조 모니터링 — templates/dashboard.html
구성 어휘: Grafana 패널 그리드·stat 임계값 틴트 / Datadog 필터 칩·심각도 띠 / MES 설비 타일
```
1280 [상단바: 제품명 라인명                     기준 09:00 | 새로고침]
     [툴바: 검색 | 공정 | 칩 x                  | 전체 20 | 주의만 6 ]
     [stat 수율][stat 가동률][stat WIP][stat 알람]  임계값 넘으면 면 틴트
     [설비 상태 보드 span-8                ][알림 span-4: 띠+확인   ]
     [SPC 추세 span-6: 한계선·이탈 점      ][공정별 막대 span-6: 축 ]
     [로트 표 span-12: sticky 헤더, 36px 행, 홀드 행 틴트              ]
834  상단바 > 툴바 > stat 1줄 > 설비 전폭 > 알림 반폭 > 차트 2열 > 표(키트 CSS 기본, 바꾸면 1-1 표)
390  상단바 > 검색 > stat 2열 > 알림 > 설비 > 차트 > 표(가로 스크롤은 표 안에서만)
```
- 순서: 상단바 → 툴바 → 상태 배너 → stat → 설비·알림 → 차트 → 표
- 배치: 첫 화면에 stat 행과 미확인 알림 / 패널은 12열 span(8+4, 6+6, 12) / 패널은 1px 선, 그림자 없음
- 배치: stat 칸 수는 과제가 묻는 지표만(4칸 공식 금지) / 숫자 우정렬·고정폭 / 차트는 축·한계선·값 표기
- 톤: 제목은 명사(설비 상태, 알림)
- 톤: 값은 숫자+단위, 증감은 '전일 대비 +0.6'
- 톤: 상태 단어 고정(가동·대기·예방보전·고장·비가동)
- 톤: 버튼은 동사 1~2자(확인, 새로고침)
- 톤: 설명 문장 없음, 기준 시각만
- 그림: 1~2장(시안의 그림 자리를 따른다. 예: 알림 빈 상태 1/1 + 상단 띠 3/1 선택). 폴백 빈 알림 02-no-alerts(1/1), 빈 결과 01-empty(1/1)

반도체 현장 화면 관례(일반 도메인 지식, 검토 필요):

| 항목 | 규칙 |
|---|---|
| 설비 상태 | 5상태 축약: RUN 가동=ok · IDLE 대기=info · PM 예방보전=warn · DOWN 고장=bad · OFF 비가동=off. 색만으로 구분 금지(좌측 띠 + 글자) |
| 지표 순서 | 수율(%) → 가동률(%) → WIP(lot) → 사이클 타임 → MTBF/MTTR. 큰 숫자 + 단위 + 전일 대비(알람은 감소가 개선). 단위 혼재는 열 이름에 단위 |
| 로트 표 | LOT ID(모노) → 제품·공정 → 설비 → 수량(우정렬) → 시작·종료(HH:MM, 시간대 명시) → 상태 배지 → 홀드 사유. 홀드 행 틴트, 20행 넘으면 필터 |
| SPC | `K.spark(값, {limits:[LCL, UCL], target, lg:true})`: 한계 점선·목표선·이탈 점. 메타에 UCL/LCL 값과 단위 |
| 알람 | Critical/Major/Minor → bad/warn/info, 최신순, 확인 버튼 → 확인자·시각 |

## 2. 조회·검색 — templates/tool.html
구성 어휘: Linear 필터 바+36px 행 / GitHub Issues 상태 카운트·라벨 / Sentry 목록·상세 split+탭
```
1280 [상단바                                              기준 09:00]
     [검색 | 공정 | 정렬 | 칩 x 칩 x                       | 초기화 ]
     [전체 8 | 진행 4 | 대기 1 | 홀드 1 | 완료 2   세그먼트 카운트   ]
     [목록 40%: 배지 ID 제목 시각, 36px][상세 60%: ID 배지 | 행동 2  ]
     [선택 행 틴트                     ][탭: 개요 | 관련 알림 | 이력 ]
     [                                 ][kv 표 + figure 16/9 1개     ]
834  목록 위 · 상세 아래(1열, 키트 기본) 또는 목록 35% 유지(페이지 CSS 로 .split 덮어씀 · 1-1 표에 기록)
390  검색 > 세그먼트(가로 스크롤) > 목록 > 상세(아래로 이어짐, 목록으로 버튼)
```
- 순서: 상단바 → 필터 바 → 세그먼트 → 상태 배너 → 목록|상세
- 배치: 행은 한 줄 36px, 넘치면 말줄임 / 걸린 필터는 칩으로 보이고 x 로 해제 / 카운트는 필터 뒤 숫자
- 배치: 선택은 주소 #ID 로 남김 / 상세 행동은 2개 이하(주 1 + 보조 1) / 빈 결과는 원인+초기화 버튼
- 톤: 열 이름에 단위(수량(매))
- 톤: 칩은 '공정: ETCH' 형식
- 톤: 상세 제목은 ID, 시각은 HH:MM
- 톤: 빈 상태는 무엇이 없나 + 다음 행동
- 톤: 행동은 결과 동사(재배정 요청, ID 복사)
- 그림: 1~2장(시안의 그림 자리를 따른다. 예: 상세 개요 탭 16/9 과제 전용 흐름·위치 + 빈 결과 1/1). 폴백 빈 결과 01-empty

## 3. 운영자 콘솔 — kit.html 폼 블록(+ 목록은 tool.html split)
구성 어휘: Vercel 설정 화면(좌 내비 + 720px 본문 + 위험 구역)
```
1280 [상단바: 제품명                                   | 저장 상태 ]
     [좌 내비 180 ][본문 720: 화면 제목 / 단계 표시 1-2-3          ]
     [ 일반       ][폼 카드: 라벨 위, 입력 40px, 도움말·오류 아래  ]
     [ 알림 규칙  ][버튼: primary 1 + ghost 1                      ]
     [ 권한       ][위험 구역: 빨간 선 상자, 맨 아래               ]
834  상단바 > 내비 가로 스크롤(접힘, kit.html 기본) > 폼 1열(720 이하) > 위험 구역
390  상단바 > 내비 가로 스크롤 > 폼 1열 > 위험 구역
```
- 순서: 상단바 → 좌 내비 → 제목 → 단계 → 폼 → 저장 → 위험 구역
- 배치: 본문 폭 720 이하 / 한 화면에 primary 버튼 1개 / 위험 행동은 위험 구역 안에만
- 배치: 저장 결과는 토스트(같은 동사) / 목록 관리가 필요하면 폼 아래가 아니라 tool.html split
- 톤: 라벨은 명사(공지 제목)
- 톤: 도움말은 입력 아래 1줄
- 톤: 오류는 고치는 법까지(1 이상이어야 합니다)
- 톤: 버튼은 동사(발행, 임시 저장), 진행 중엔 '발행 중'
- 톤: 위험 구역은 결과를 말한다(되돌릴 수 없습니다)
- 그림: 1~2장(시안의 그림 자리를 따른다. 예: 본문 머리 4/3 1개 또는 빈 목록 4/3). 폴백 빈 목록 05-upload(4/3)

## 4. 모바일 — templates/mobile.html
구성 어휘: Toss 큰 숫자·전폭 CTA·바텀시트 / 배민·쿠팡 56px 행+하단 탭
```
390  [앱바: 화면 이름                       알림 수]
     [상태 배너                                    ]
     [라벨 / 큰 숫자 40px + 단위 / 다음 할 일 1줄  ]
     [전폭 CTA 48px                                ]
     [56px 행: 배지 | 제목+설비 | 시각 >           ]
     [56px 행 ...                                  ]
     [하단 탭 3~4개 (safe-area)                    ]
834  가운데 480px 한 열(데스크톱과 같음)
1280 가운데 480px 한 열 그대로(데스크톱 배치 따로 없음)
```
- 순서: 앱바 → 배너 → 큰 숫자 → CTA → 목록 → (알림) → 하단 탭
- 배치: 첫 화면 = 큰 숫자 1 + 행동 1 + 목록 첫 2행 / 표·다열 그리드 금지 / 터치 타깃 44px, 행 56px
- 배치: 입력은 바텀시트(페이지 이동 없이) / 하단 탭은 같은 페이지 안 섹션 이동
- 톤: 큰 숫자 라벨은 명사(오늘 남은 점검)
- 톤: CTA 는 다음 행동 1개(다음 점검 시작)
- 톤: 행 제목은 할 일
- 톤: 완료 토스트는 같은 동사(점검 완료 저장)
- 톤: 오류는 짧게 + 다시 시도
- 그림: 1~2장(시안의 그림 자리를 따른다. 예: 상단 그림 4/3 또는 완료 1/1 + 빈 목록 1/1). 폴백 완료 03-done(1/1), 빈 목록 01-empty(1/1)
