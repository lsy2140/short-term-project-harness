# 프롬프트 예시 25 — 구간별 복사용 (`python3 scripts/prompt.py <번호|키워드>`)

위임 프롬프트의 뼈대는 `docs/delegation_prompts.md`(목표 / 범위 / 제약 / 완료 조건 / 검증 5요소 + 마지막 두 줄)다. 이 문서는 그 뼈대를 **구간별 상황 25개**로 펼친 것이다. `[빈칸]`은 과제에 맞게 바꾼다. 각 예시는 제목 / 본문 / 이 프롬프트가 막는 실수 한 줄 / 출처로 되어 있다.

## 사용법
```bash
python3 scripts/prompt.py            # 목록(번호 · 제목 · 구간)
python3 scripts/prompt.py 11         # 11번 본문만 — 복사해서 Codex 에 붙여넣는다 (토큰 0)
python3 scripts/prompt.py 트레이스백   # 키워드(제목·키워드·구간) 검색. 1개면 본문, 여러 개면 후보 목록
python3 scripts/prompt.py --all      # 전체 본문
```
형식은 `scripts/prompt.py` 가 읽는 계약이다(`tests/test_prompt.py` 가 고정): `## N. 제목` → `- 구간:` → `- 키워드:` → 코드 블록(본문) → `- 막는 실수:` → `- 출처:`. 번호 없는 절(이 절·출처 목록·운영 의견)은 예시로 세지 않는다.

| 구간 | 번호 | 개수 |
|---|---|---|
| 킥오프 (0~10분) | 1~3 | 3 |
| 인터뷰 (10~30분) | 4~7 | 4 |
| 첫 완주 (30~63분) | 8~10 | 3 |
| 규칙 구현 (63~130분) | 11~15 | 5 |
| 캐내기 (기능 하나 끝날 때마다) | 16~17 | 2 |
| 디버그 (FAIL 시) | 18~19 | 2 |
| 문서 (144~165분) | 20~22 | 3 |
| 심사자 (130·165분, 별도 세션) | 23 | 1 |
| 서술형 (165분~제출 확정 전) | 24~25 | 2 |

출처 표기: `참고/…`는 `9. 참고_공개저장소/` 아래 경로(2026-10-29 clone 기준 줄 번호), `키트/…`는 이 저장소 파일, `웹①·웹②`는 문서 끝 출처 목록의 검색 결과다.

## 5. 담당자 창에 붙여넣는 질의 메시지 틀
- 구간: 인터뷰
- 키워드: 담당자 창, 메신저, 질의 메시지, 업무 사실

```
5. [기준값]과 같은 값은 포함인가요, 제외인가요? 단위와 시간대는요. (경계값 처리를 정하려고요)
6. 절대 나가면 안 되는 결과는 무엇인가요? 그게 나가면 누가 어떤 손해를 보나요. (가드레일로 막으려고요)
7. 데이터가 없거나 처리가 실패하면 화면·파일에 무엇을 보여야 하나요? (실패 시 표시를 정하려고요)
8. 결과 [화면/API/파일]은 목록만 있으면 되나요, 건수·요약이 같이 붙나요? 열 순서는요. (출력 모양을 맞추려고요)
```

## 보조 세션 운영 의견 (개선계획 6절 요지)
- **보조 Codex 세션 상시 운영은 권하지 않는다.** (1) 토큰 사용량이 채점 기록이다 — 리허설 1에서 해결자 세션만 32.6M 토큰이었다. (2) 터미널 왕복이 집중을 끊는다 — 리허설에서 담당자·심사자 세션 전환으로 이미 시간을 잃었다. (3) 이 문서 25개로 90%는 해결된다.
- **대신 1회성 3회만**: 10분(첫 질문 5~8개 다듬기 — 예시 4), 130분(`$probe-judge` 별도 read-only 세션 — 예시 23), 165분(서술형 초안 다듬기 — 예시 24·25). 세 번 모두 새 터미널의 `codex -s read-only` 로.
- **토큰 0 대안**: `python3 scripts/prompt.py <번호|키워드>` 로 템플릿을 터미널에 찍어 복사한다. 해결자 세션의 컨텍스트에는 아무것도 들어가지 않는다.
- 리허설 2(과제E)에서 세 번을 실제로 쓰고, 안 쓴 회차는 회고에 "불필요"로 적는다.
