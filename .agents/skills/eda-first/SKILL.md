# eda-first

목표: 토큰을 아끼면서 데이터의 함정을 먼저 찾는다.

## 절차
1. `python3 scripts/eda_bootstrap.py <파일...> --out eda_summary.md` 실행 → `eda_summary.md`만 읽는다. 원본을 `cat`하지 않는다.
2. 표에서 확인: 결측률 높은 열 / 키 후보 없음(중복) / 날짜로 보이는데 str로 추정된 열(형식 혼재) / 수치인데 str(쉼표·단위 포함) / 상위 빈도값에 '없음·N/A·-' 같은 결측 표기.
3. 다음 질문을 TASK.md 3번에 추가: 결측 처리, 중복 처리, 경계값 포함 여부, 단위·시간대, 정렬·tie-break, 제외 조건.
4. 샘플 5행만 `head -5`로 확인해 요약과 맞는지 대조한다.
4-1. 현미경 단계: 사람이 지정한 그룹 열(라인·공급사·기간 등)별로 행 수·평균·최소·최대·결측률을 표로 만들고, 시간 열이 있으면 일별 추세(건수·평균)를 10줄 이내 표로 낸다. 그룹 간 분포가 다르면(단위·시간대·형식 혼재 의심) 그 사실만 보고하고 해석은 사람에게 맡긴다.
4-2. 경계 케이스 등록: EDA에서 발견한 임계값·날짜 경계·중복 키를 즉시 경계 케이스로 만든다. `python3 scripts/make_edge_cases.py <주 CSV> --out data/edge/`를 실행하고(empty·dirty·dup·shuffled·extra_col·header_only_diff 생성), 케이스마다 "무엇을 시험하는지" 한 줄을 TASK.md 5번 옆에 적는다(예: dup.csv — 완전 중복 행이 집계에 두 번 들어가나). 임계값과 같은 값/±1, 날짜 경계(자정·월말·Z 시각) 행은 표에 직접 적어 `$unit-test-starter`의 경계 케이스로 넘긴다.
5. 응시자에게 보고: 행·열 / 키 / 위험 열 3개 / 처리 규칙 질문 목록. 10줄 이내.

## 금지
- 데이터 전체 출력, 정제·모델링 착수(계약 전).
