# narrative-prep

목표: 서술형 시작 전에 **내 제출물에 대한 질문 6개와 답변 골격**을 문서로 남겨 머릿속에 고정한다. (서술형 단계에서는 AI·문서 복사 모두 금지이므로, 이 단계는 **제출 확정 전**에 끝낸다.)

## 절차
1. `TASK.md`(가정·안 할 일·못 한 것), `DECISIONS.md`(합의문·구조·데이터·믿지 않은 것·실패 지점), 테스트 결과 요약을 읽는다.
2. `docs/서술형_대비.md`의 질문뱅크에서 내 제출물에 해당하는 질문 6개를 고른다(의도 2, 기술 2, 인지 2).
3. 각 질문에 4문장 골격으로 답변 초안을 쓴다: **사실**(문제에 쓰여 있던 것) → **결정**(내가 정한 것) → **근거**(왜, 어떤 검증) → **한계**(어떤 입력에서 틀리나). 제약(표준 라이브러리·시간·데이터)이 결정을 바꾼 경우에는 **제약 1개의 대가**(무엇을 잃나·크기)와 실무 대안 2개, 그래도 따른 이유를 한 줄씩 덧붙인다.
4. 수치는 실제 값(테스트 수, 행 수, 경계값)을 넣는다. 모르는 것은 "확인하지 않았습니다. 확인하려면 ___"로 쓴다.
5. `~/narrative_draft.md`(과제 폴더 밖, 제출물에 섞이지 않게)로 저장하고 응시자에게 **소리 내어 읽을 3개**(상충 조건 / 가장 위험한 실패 / Codex를 믿지 않은 지점)를 표시한다.
6. 초안 중 응시자가 자기 말로 설명하지 못할 문장을 짚어 표시하고, 전문 용어 없이 다시 쓴다. 설명 못 하는 문장은 서술형에서 쓰지 않는다.

## 금지
- 제출물에 없는 기능·검증을 있는 것처럼 쓰기. 서술형 진행 중 사용.
